# HyperOS 4 / MIX2S · AE 0.0.0.3 · R3

基于 **AEmulator 0.0.0.3** 的 HyperOS 4 客体修复整合包。我认为当前版本已基本满足使用需求。

合入铃声音频索引、1080×2160 / 403 DPI 显示修正、天气等预装应用库注册和浏览器安装兼容处理，继承基包 GLES、WebView、音频和模拟电话/短信修复。不修改宿主系统或 AE APK。

## 下载

原 ZIP 约 4.39 GB，因此分为多个小于 2 GiB 的附件。

1. 下载所有 `.partNNN`、`parts.json` 和 `join_release.ps1`（Windows）或 `join_release.py`（Python）。
2. 同目录运行合并工具，校验所有分卷及合并后的原 ZIP。
3. 在 **AE 0.0.0.3** 导入合并后的 ZIP，首次启动前手动设置 **1080×2160 / 403 DPI**，初始化后正常重启一次。

这不是 7-Zip 分卷压缩，请用提供的合并工具还原。
