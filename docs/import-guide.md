# 导入说明

1. 按[下载和合并说明](release-download.md)把三个分卷合成 `HyperOS4-AE0.0.0.3.zip`。
2. 在 **AE 0.0.0.3** 里新建实例，选择 ZIP 导入。
3. 推荐设置 **1080×2160 / 403 DPI**，默认的 540×960 / 240 DPI 也可以启动。
4. 首次开机等约 2–3 分钟，内置应用和媒体库初始化完成后重启一次。

这个包只用于 AE 虚拟机，不能给实体手机刷。K80、Neo11 已测试，可以导入运行。

## 更换分辨率

在 AE 实例设置中修改宽高和 DPI，然后正常关闭、启动实例。系统会在启动时同步显示参数，不能运行中热切换。

测过 **720×1280 / 320** 和 **1080×2160 / 403** 双向切换。画面保持等比，宽高比不一致时可能有黑边。

## 使用时留意

- 首次开机会自动扫描 56 个内置铃声、通知和闹钟音频，不需要手工补扫。
- 日历日期和时钟指针是固定的，不会实时更新。
- 液态玻璃、部分图标黑块和安全中心异常还没解决。

ZIP 内的说明是在打包时写的，其中内部编号和测试状态没再改过。后续测试结果见[测试记录](validation.md)，使用说明以仓库和 Release 页面为准。
