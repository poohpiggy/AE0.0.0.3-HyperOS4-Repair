# HyperOS 4 for AE 0.0.0.3 · 导入说明

1. 按 [分卷说明](release-download.md) 下载这一轮的 3 个分卷，合并为 `HyperOS4-AE0.0.0.3.zip`。不要混用旧分卷。
2. 在 **AE 0.0.0.3** 新建实例，选择 ZIP 导入。只用于虚拟机，不用于实体手机刷机。
3. 推荐 **1080×2160 / 403 DPI**。默认 540×960 / 240 的首次启动也已经验收通过，不再把 1080 / 403 写成唯一能启动的参数。
4. 首次开机等约 2–3 分钟，完成内置应用和媒体索引初始化，再正常重启一次。应用协议和权限照常自己决定。

## 想换分辨率

在 AE 实例设置里改宽高和 DPI，正常关闭/启动实例。内部显示参数会在 SurfaceFlinger 启动前同步，外层保持等比；宽高比不一致时可能留黑边。

已验证 **720×1280 / 320** 与 **1080×2160 / 403** 双向切换，没有穷举所有组合，也不是运行中热切换。403 是这套实例配置的逻辑 DPI。

## 这次首启检查

新 ZIP 已经重新干净导入，第 1 次启动自动登记了 56 个系统铃声/通知/闹钟音频，不需要手工补扫。详情见 [验收记录](validation.md)。

静态日历的日期、静态时钟指针不会实时更新；液态玻璃、部分图标黑块和安全中心异常仍有问题。

包内说明保留了构建时的内部编号和当时“尚未导入”的状态；后续验收结果在 ZIP 旁的报告里。这次没有修改已验收的 ZIP 字节，当前说明以此页面和 Release 为准。
