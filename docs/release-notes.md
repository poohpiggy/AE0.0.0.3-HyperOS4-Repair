# HyperOS 4 for AE 0.0.0.3

这轮继续补了显示、多任务、浏览器和首次开机的问题，包体已经重新干净导入验证。

## 更新了什么

- 改 AE 分辨率/DPI 后重启，SurfaceFlinger 启动前同步显示配置；已测 720×1280 /320 与 1080×2160 /403 双向切换。
- 多任务卡片和实际预览修复。
- 官方浏览器 66 个 ARM64 库，解决预置应用第一次启动缺库闪退。
- 静态天气/日历/时钟兼容显示，圆角与居中放大；日历日期和时钟指针固定。
- 首启等 MediaProvider 真正可查询后再扫描内置音频，修复候选新导入时的漏项。

当前新 ZIP 已用 AE 原生导入器干净导入。验收时 **bootCount=1，首次启动自动登记全部 56 个内置音频**，用户确认可以正常使用。浏览器、多任务、图标和显示切换在紧邻候选中验证；最后只增加媒体服务等待逻辑，未再次穷举分辨率或重测来电听感。作者另已确认：**K80 和 Neo11 均通过当前新包的导入运行测试**。

## 下载

下载带 **f55fceb6** 的 3 个 `.part001` / `.part002` / `.part003`，以及 `parts.json`。Windows 再下载 `join_release.ps1`，其他环境可用 `join_release.py`；具体命令在 `README_DOWNLOAD.md`。

还原后文件名为 `HyperOS4-AE0.0.0.3.zip`，约 4.48 GB / 4.17 GiB。合并工具会检查每一卷和整包的哈希。

```text
f55fceb63243a7f89533de1f341f3329c7da6c83e5ce6746d69a0167d7704391
```

推荐 AE 参数 **1080×2160 /403 DPI**。默认 540×960 /240 的首启也已验收；改显示参数后正常重启实例，第一次初始化等约 2–3 分钟。

## 已知问题与来源

液态玻璃、部分图标黑块、安全中心启动异常仍在；静态图标不会实时更新。只用于 **AE 0.0.0.3 虚拟机**，不给实体手机刷机，不修改 AE APK 或宿主系统。

公开名称和 Release 仍只有这一份。包内的早期编号及“构建时尚未导入”是历史记录，后续验收没有回改 ZIP 字节。
