# HyperOS 4 for AE 0.0.0.3

这是一份在 AE 虚拟机里使用的 HyperOS 4 适配包，主要折腾了 GLES 渲染、原生桌面、声音、模拟来电/短信、铃声选择、显示比例和部分内置应用安装。

**基于 AE 0.0.0.3，已在 K80 和 Neo11 上完成导入测试，两台均可运行。** 这是作者补充的实际测试结果。仍有一些问题，尤其是动态图标和部分玻璃效果，还没完整解决。

## 怎么下载

包体约 4.39 GB，超过 GitHub 单附件限制，因此分成了 3 份。

1. 下载全部 `.part001`、`.part002`、`.part003`，以及 `parts.json`。
2. Windows 再下载 `join_release.ps1`；其他环境可以用 `join_release.py`。
3. 按 `README_DOWNLOAD.md` 合并，还原成 `HyperOS4-AE0.0.0.3.zip`。
4. 导入 AE，首次启动前设置 **1080×2160 / 403 DPI**，初始化完成后正常重启一次。

这是普通二进制分卷，不是 7-Zip 分卷格式。合并工具会核对每一卷和完整 ZIP 的 SHA-256。

```text
dd01bd45975d6b8a02a69aa0080320b47e8f160781fe2bf3940ee091f2919333
```

包体没有重新打包，仍是已经测试过的那份，只统一了公开文件名。包内旧说明如果带有内部编号，是制作过程中的标记；下载和使用以这里的说明为准。
