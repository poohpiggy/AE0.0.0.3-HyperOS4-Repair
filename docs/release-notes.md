# HyperOS 4 for AE 0.0.0.3

这次主要补了分辨率、多任务、浏览器闪退和首次开机的铃声扫描。**K80、Neo11 都已测试，可以导入运行。**

## 更新内容

- 改 AE 分辨率和 DPI 后，重启就能同步内部显示参数，解决画面缩小、裁切的问题。
- 修复多任务卡片空白，设置和浏览器能显示预览。
- 补齐浏览器缺的 66 个 ARM64 库，解决首次启动闪退。
- 调整天气、日历和时钟的静态兼容图标。
- 首次开机等待媒体服务就绪再扫描铃声，新实例首启能自动登记全部 56 个内置音频。

## 下载和导入

下载文件名带 `f55fceb6` 的三个分卷，以及 `parts.json` 和合并脚本。Windows 用 `join_release.ps1`，其他环境可以用 `join_release.py`，操作见附件 `README_DOWNLOAD.md`。

合并后是 `HyperOS4-AE0.0.0.3.zip`，约 **4.48 GB / 4.17 GiB**。在 **AE 0.0.0.3** 新建实例导入，推荐 **1080×2160 / 403 DPI**。第一次开机等约 2–3 分钟，初始化完成后重启一次。

默认 540×960 / 240 DPI 也能启动。以后改显示参数，需要重启实例才会生效。

液态玻璃、部分图标黑块和安全中心启动异常还没解决。日历日期和时钟指针是固定的，不会实时更新。测试细节见[测试记录](https://github.com/poohpiggy/AE0.0.0.3-HyperOS4-Repair/blob/main/docs/validation.md)。
