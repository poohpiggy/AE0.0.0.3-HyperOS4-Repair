# HyperOS 4 for AE 0.0.0.3

把最近修的东西打进包了，K80、Neo11 都导入试过，可以运行。用 **AE 0.0.0.3**。

这次改了这些：

- 改分辨率后画面缩小、裁切的问题处理了，改完 AE 设置重启就能同步。
- 多任务能看到设置和浏览器的预览了。
- 补上浏览器缺的库，修了第一次打开就闪退的问题。
- 调了一下天气、日历和时钟的静态图标。
- 修了新导入后铃声扫不全的问题，重新导入测试时首启能扫到全部 56 个内置音频。

液态玻璃、部分图标黑块和安全中心启动异常还没弄好。日历日期和时钟指针是固定的，不会实时更新。[详细测试记录](https://github.com/poohpiggy/AE0.0.0.3-HyperOS4-Repair/blob/main/docs/validation.md)。

## 怎么下载

包约 4.48 GB，拆成了三份。下载名字带 `f55fceb6` 的三个分卷，再下 `parts.json` 和合并脚本，放到同一个文件夹里。Windows 用 `join_release.ps1`，其他环境可以用 `join_release.py`，具体步骤在附件 `README_DOWNLOAD.md`。

合并成 `HyperOS4-AE0.0.0.3.zip` 后，到 AE 新建实例导入。推荐 **1080×2160 / 403 DPI**，默认 540×960 / 240 DPI 也能启动。第一次开机等个 2–3 分钟，初始化完再重启一次。

这个包只给 AE 虚拟机用，别给实体手机刷。
