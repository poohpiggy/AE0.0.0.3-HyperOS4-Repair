# HyperOS 4 for AE 0.0.0.3

> **基于 AEmulator（AE）0.0.0.3。** 面向 AE 虚拟机的 HyperOS 4 适配与折腾记录，保留原生桌面，采用 OpenGL ES 渲染路径。

这是我排查 AE 虚拟机兼容问题、验证修复并整理 AE 导入包的折腾记录。仓库包含保留下来的修复脚本、库注册声明、打包工具和校验依据。文中的“客体”就是 AE 里面的虚拟系统。**补丁只改这里，不修改宿主系统或 AE APK。包体仅供 AE 导入，不用于实体手机刷机。**

## 目前做了什么

- **铃声与提示音**：通过 MediaProvider 为系统铃声、通知和闹钟建立索引，不搬运旧实例媒体数据库。
- **显示与原生界面密度**：同步 AE 实例几何、逻辑 DPI 和 MIUI 密度元数据。403 是这套实例配置采用的逻辑 DPI。
- **天气等预装应用**：补充 `hyperos.rustruntime.v3/v5` 和 `miui-uninstall-empty.jar` 的真实库声明；已安装应用保留，不清除用户数据或协议选择。
- **浏览器安装冲突**：旧预置 APK 移出扫描位置并备份，使用商店原签名版本，保留系统签名校验。
- **启动持久化**：兼容运行文件从系统分区恢复，默认设置仅首次应用；媒体扫描失败时不写成功标记。
- **打包与核验**：镜像合并后 `e2fsck -fn`，ZIP64 高压缩，再逐成员解压核对大小、SHA-256 和 CRC。

GLES、WebView、音频和模拟电话/短信等改动是前面几轮逐步合进去的，具体见过程记录。部分早期原生补丁源码没有保留下来，仓库不是从原厂 ROM 一键重建的完整工程。

## 下载与导入

[下载适配包](https://github.com/poohpiggy/AE0.0.0.3-HyperOS4-Repair/releases/tag/hyperos4-ae0.0.0.3)。包体按 GitHub 单附件限制分卷；下载所有分卷及合并工具后，按 [合并说明](docs/release-download.md) 还原原始 ZIP。

ZIP SHA-256：

```text
dd01bd45975d6b8a02a69aa0080320b47e8f160781fe2bf3940ee091f2919333
```

导入前在 AE 0.0.0.3 中配置 **1080 × 2160 / 403 DPI**。首次初始化后正常重启一次，详见 [导入说明](docs/import-guide.md)。

## 还有哪些没做好

时钟、日历目前保留静态兼容图标；动态图标和部分玻璃效果还没完整解决。K80 和 Neo11 的导入运行测试已通过，但不等于每个功能都逐项测完。
