# HyperOS 4 for AE 0.0.0.3

基于原作者的包，给 AE 0.0.0.3 修了一些问题，保留了原生小米桌面。

一开始在弄 VK 转 GL，后来发现桌面、声音、浏览器这些地方也有问题，就接着往下修了。最近主要在弄分辨率、多任务，还有新导入后铃声扫不全的问题。用到的脚本和查错过程整理在这里，方便以后自己查，也给遇到类似问题的人参考。

**[下载包](https://github.com/poohpiggy/AE0.0.0.3-HyperOS4-Repair/releases/tag/hyperos4-ae0.0.0.3)** · [导入说明](docs/import-guide.md) · [修改日志](CHANGELOG.md) · [查错过程](docs/troubleshooting.md)

## 下载使用

我在 **K80 和 Neo11** 上都试过了，可以导入运行。用的是 **AE 0.0.0.3**，其他版本还没试。

包有点大，约 4.48 GB，所以拆成了三份。到 Release 把三个分卷、`parts.json` 和合并脚本下齐，放在同一个文件夹里，按[这里的步骤](docs/release-download.md)合并，再到 AE 新建实例导入。

分辨率推荐 **1080×2160，403 DPI**，默认的 540×960 / 240 DPI 也能启动。第一次开机等个 2–3 分钟，初始化完再重启一次。以后想换分辨率，改 AE 里的设置再重启就行。

这是虚拟机用的包，别拿去给实体手机刷。

## 这次改的地方

- 改分辨率后画面缩小、裁切的问题处理了，现在会在开机时同步尺寸和 DPI。
- 多任务卡片不再是空白，能看到设置和浏览器的预览。
- 浏览器缺的库补上了，修了第一次打开就闪退的问题。
- 天气、日历、时钟用了静态图标，又调了一下圆角和大小。
- 新导入后铃声漏扫的问题也修了。这次重新导入试过，第一次开机就能扫到全部 56 个内置音频。

这几项的过程在[这篇记录](docs/latest-repairs.md)里，之前 VK 转 GL、声音、模拟来电等内容放在[前面的记录](docs/journey.md)里。

## 还没修好的

液态玻璃、部分图标黑块、安全中心启动异常还在。日历日期和时钟指针也是固定的，不会跟着时间变。

分辨率切换试了 720×1280 / 320 和 1080×2160 / 403 两组，其他组合没全试。更细的情况放在[测试记录](docs/validation.md)里。
